# Jobs in Mexico (WP09)

Streamlit app for the ENOE studies of WP09. It only displays precomputed outputs from `empirics/output/enoe/<study>/`; the pipelines are in `empirics/code/enoe/` and the papers in `papers/WP09_jobs_mexico/`.

Run locally: `streamlit run apps/jobs_mexico/app.py`. On Streamlit Community Cloud the main file path is `apps/jobs_mexico/app.py`.

| Page | Content |
|---|---|
| The programme | Question, structure of the studies and their status |
| 9.1 Which jobs are rungs? | ENOE rotating panel: exit and upward-move rates by sector and by firm size × formality, Shapley comparison with robustness variants, manufacturing vs services, transitions between not employed, informal and formal work, earnings growth, reporting reliability |
