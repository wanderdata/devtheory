Both UN files reproduce the committed Caribbean extracts (`interim/carib_lp/un_va_*.csv`) exactly (82 series checked, maximum relative difference 2e-16), so they are the vintage used for WP05.

Used by: `carib_lp` (WP05), the LAC extension of it, and the development-motors project.

The ILO files are a newer download (2026-11-09) than the one behind WP05 (2026-11-05). For the 16 Caribbean countries they are identical: every modelled value (34,020 rows) and every survey value (17,167 rows) is unchanged. The only difference is that ILO relabelled the source code of Haiti's 2012 survey from `BB:14099` to `BB:7725`, with the same values.

The five ILO labour-market series (rates, output per hour, hours) reproduce the Caribbean extract used by the dashboard exactly.

Used by WP08 (steps 08 and 09 of `lp`): ILOSTAT population (demographic term) and WDI population aged 65+ (context column). The ILOSTAT file of employment by age received on 2026-11-12 (`EMP_2EMP_SEX_AGE_NB_A`) has only the bands 15–24, 25+ and 15+, so it is not used or kept; population by age (`POP_2POP_SEX_AGE_NB_A`) is no longer in the ILOSTAT bulk list (D-044).

The full INEGI methodology book (*Fuentes y metodologías, año base 2018*, 688 PDF pages, 41 MB, SHA-256 `f34e4459039832763c8397a64a0d0c9d48b473c3d1997e5a92ecfb59b219542c`) is too large for the repository; only the two sections used are committed.

INEGI's MEITEF tabulados (480 xlsx files, 2005Q1–2026Q1, updated 2026-09-03) are kept unmodified as `inegi_meitef_base2018_tabulados_2005q1-2026q1.zip` (125 MB, SHA-256 `d1ef95e826b083f5a769da12c08607511d90296ad642cb3581b0bfff4a636678`) in the uncommitted `empirics/data/raw/inegi/`, and as the asset of release `inegi-meitef` of this repository (asset `tabulados_MEITEF.zip`, created by the user), from which `00_meitef.py` downloads it when it is missing. The tables by state within each activity repeat the figures of the tables by activity within each state and are not read; activity totals match the sum of activities to 1e-7 and the states sum to the national total. State GDP is read by `empirics/code/enoe/states/gdp.py`; the 32 states add up to the national total in every year (maximum relative difference 4e-16).
